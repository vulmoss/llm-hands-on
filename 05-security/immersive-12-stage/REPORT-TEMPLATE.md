# 报告和复盘模板

## 五要素简报

- 标题：身份 + 被突破的边界 + 已观察结果。
- 前置：固定代码/镜像版本、靶场地址、合成账号、初始化状态。
- 步骤：正常请求 → 只改变一个变量 → 异常响应 → 正常/修复对照。
- 证据和影响：文件名/请求编号/截图；已证实影响；未证实扩展。
- 修复及回归：服务端修复点、异常应拒绝、正常业务应保留。

## 六段完整报告（每个发现一份）

### 1. 概述与范围

名称、日期、操作者、课程靶场、源码 SHA、镜像 digest、授权范围。F/N 分类及依据；教学严重性判断与依据，不假装属于某 SRC 的正式评级。

### 2. 前置条件与正常行为

身份、对象所有者、预期规则、会话/安全级别/数据初始化；正常请求及响应证据。Cookie 与 token 脱敏，示例账号也标为合成。

### 3. 复现步骤与最小证据

逐步命令/页面操作、修改字段、预期和实际结果、证据路径。截图配可复制请求摘要；保留必要字段，不导出整表。标明使用的是 DVWA、Juice 或微型实验，不能拼接不同系统冒充同一修复。

### 4. 根因与影响

源码位置/权限检查路径、已确认因果；仅推测的根因另列。说明影响对象和前置条件，正常行为为什么排除。AI 原始主张与人工修正分别记录。

### 5. 修复与验证

修复点、实现建议、异常/正常回归、修复前后差异。只看到演示 fixed 模式时，写“教学对照验证”，不写“生产已修复”。

### 6. 稳定性、局限与后续

| 次数 | 会话/数据状态 | 正常对照 | 异常对照 | 修复对照 | 证据 | 结果/失败原因 |

| 2 | | | | | | |
| 3 | | | | | | |

附未验证项、模型/工具错误、请求次数、人工审批摘要（若适用）、停止方法。报告仅保存到本地课程目录；提交外部平台是另一个独立动作。
