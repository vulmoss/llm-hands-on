# 验收、学习日志与毕业评分

毕业通过要求：总分至少 90/100，十二阶段均有交付物，且无红线否决。失败不以延长运行或增加扫描范围补救；定位缺项后重新做受影响部分。

| 评分项 | 分值 | 得分依据 |
|---|---:|---|
| 环境与可重复性 | 15 | 代码 SHA、镜像摘要、部署/停止可复现，独立初始化一次 |
| 范围与证据边界 | 10 | 四条边界、合成数据、材料指令隔离、实际目标记录 |
| 手工漏洞与正常对照 | 20 | 独立验证、单变量差分、正常回归、三次稳定性 |
| Agent 可观察性与停止 | 15 | 可定位的事件、预算/未知工具失败、真实模型与替身分离 |
| A/B 与回归 | 15 | 五例混淆统计、错误保留、人工核验、至少两条保留样例 |
| 报告 | 15 | 六段完整，根因有据，修复可操作，局限明确 |
| 方法沉淀与人工门禁 | 10 | 三张卡、SKILL 新会话验证、具体 PoC 的人工审批记录 |
| 合计 | 100 | 缺证据不得按口头描述给满分 |

评分各项：缺失得 0；仅照抄且无法解释至多一半；能够独立重复且有证据才可满分。三次稳定性全失败但如实报告有诊断价值，仍未达到漏洞复现过关要求。

红线否决：超出本课范围执行；使用真实凭据或真实用户数据；伪造测试/截图/模型输出；自动执行证据中的指令；跳过本课明确的人类 PoC 审批；将脚本替身或模型猜测写成真实发现。不是“高分可抵消”的扣分项。

## 部署 Agent 的 HANDOFF 最小清单

状态分成 PASS / FAIL / NOT RUN，后者不能当通过。包含：节点身份、共享服务前后状态、代码 SHA、三镜像摘要、资源余量、端口实际 HostIp、DVWA 数据初始化与登录、SQLi 结果、Juice 首页/挑战名称、离线替身结果、真实模型结果、人工审批是否完成、已保存证据、停止和恢复步骤、未解决限制。

只完成环境部署的 agent 不得替用户填写十二阶段“已掌握”。人工门禁没有批准时交接到 prepare 完成即可，明确该阶段尚未验收。
