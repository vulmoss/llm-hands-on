# 实验报告模板

标题：主体 A 能对资源 B 执行何种不应允许的动作

- 实验时间、代码提交号、Python/浏览器/模型版本：
- 范围与实现层级：本地真实 HTTP / 简化模型 / 独立产品靶场：
- 账号与数据：只用合成身份；敏感证据先脱敏：
- 预期权限或业务不变量：

## 复现

1. 启动哪一版本，运行位置与端口：
2. 正常请求与预期结果：
3. 只改变哪一个变量：
4. 完整方法、路径、脱敏头、请求体：
5. 实际状态与最小响应片段：
6. 相同输入在修复版的结果：
7. 修复后正常业务是否保留：

## 解释

- 直接观察的事实：
- 源码根因及定位：
- 影响范围与必要条件：
- 未证明的事情与假阳性排除：
- AI 提出但尚未验证的意见：

## 修复与复测

- 应修改的服务端边界：
- 正常/异常/匿名/其他身份测试：
- 自动化命令、退出码、证据文件：
- 未覆盖的浏览器/运行时/云厂商差异：
- 清理与恢复：

严重性留给具备真实业务上下文的评估。本地合成数据没有真实资产价值；不为满足海报措辞强行升级评级。
