# 12 · 综合复现、修复与报告

目标：让另一个人仅凭报告就能重现同一结果。先修：完成主线或前 11 单元。

```bash
python3 -m llm_lab.web_security run --all --output .data/web-ai-course/final.json
python3 -m pytest -q tests/security/test_web_course.py
```

选 IDOR、SQLi 和第三个你最熟悉的实验。每个完成：正常操作 → 假设 → 一处输入变化 → 数据/权限影响 → 源码根因 → 修复 → 原始请求重放 → 正常业务回归。保留源代码提交号、Python 版本、命令、请求和响应，不只贴模型报告。

按 REPORT-TEMPLATE 编写报告：把“观察到什么”和“可能导致什么”分开。OAuth 模型不能写成真实账号接管，CORS 响应头不能写成读到了用户隐私。图片中的严重性“升级”需要额外证据，不是文字加工。

AI 用途：检查步骤是否缺前置条件、是否把推测当事实、修复是否有正常回归。只在人工审阅后整理结果；本模块不会自动向 SRC、邮件或第三方提交。

复盘指标：12 组对照是否通过；是否有业务正常对照；一次失败是否能解释；是否发现模型遗漏；能否从 Git 版本恢复；是否明确列出未测试项。报告与日志填完才算完成学习，不以运行一次命令代替掌握。
