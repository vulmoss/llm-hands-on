# 08 · 云对象策略与复杂漏洞的先修

目标：把匿名、对象路径、签名权限和解析器执行边界分开。先修：单元 05—07。

```bash
python3 -m llm_lab.web_security run --lab cloud-storage
```

匿名访问 public.txt 正常；匿名访问 private.txt 在漏洞版返回 LAB_OBJECT_MARKER，修复版 403；Alice 修复版能读 private.txt，Bob 不能。测试的是对象授权，不是 S3 签名或供应商实现。公开静态素材本身不应被报作敏感泄露；ListBucket 与 GetObject 也是不同权限。

参照 ADVANCED 的独立自有桶流程学习签名：method、object key、expiry、被签 headers、凭据权限共同影响范围。客户端得到短期 STS 凭据不天然是漏洞，关键是权限、过期和租户隔离。不要把含凭据的 URL 发给公共 AI。

RCE/反序列化/XXE/SSTI 需要语言运行时、依赖版本、解释器与进程权限等前置条件。本地 12 实验没有实现这些解释器漏洞，按 ADVANCED 选择官方隔离靶场后再记录“已复现”。先做六语言审计题理解输入到危险操作，再尝试复杂链路。

中间件和子域：版本号只产生假设；未绑定 CNAME 只产生待核实项。接管需要证实资源可被另一主体认领、域名仍指向它及内容可控制。本课程不注册/认领任何第三方资源。

产物：对象权限矩阵；一个签名范围分析；一个高级靶场的版本、前置条件、最小证据与清理记录。
