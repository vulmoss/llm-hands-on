# 资料来源与核对日期

核对日期：2026-09-23。海报来自用户上传的两张课程目录；只分析其中主题，不复制课程讲义、售卖内容或声称拥有原课代码。本模块代码和学习流程为重新设计。

- [OWASP WSTG](https://owasp.org/www-project-web-security-testing-guide/)：测试分类与证据方法。
- [OWASP Authorization](https://cheatsheetseries.owasp.org/cheatsheets/Authorization_Cheat_Sheet.html)：逐请求检查权限、默认拒绝与权限测试。
- [MDN XSS](https://developer.mozilla.org/en-US/docs/Web/Security/Attacks/XSS)：输出上下文与浏览器执行。
- [OWASP File Upload](https://cheatsheetseries.owasp.org/cheatsheets/File_Upload_Cheat_Sheet.html)：扩展名、内容、存储与大小控制。
- [PortSwigger Learning Paths](https://portswigger.net/web-security/learning-paths)：按主题继续真实隔离靶场。
- [PortSwigger OAuth](https://portswigger.net/web-security/oauth)：完整认证授权流程与实验入口。
- [Ollama Chat API](https://docs.ollama.com/api/chat)：原生聊天请求、stream 与响应字段。
- [Vue Security](https://vuejs.org/guide/best-practices/security.html)、[React DOM](https://react.dev/reference/react-dom/components/common)：框架转义与 HTML 注入接口。
- [Chrome activeTab](https://developer.chrome.com/docs/extensions/develop/concepts/activeTab)：用户触发的临时页面访问权限。

进阶文件另外链接 S3、XML、SSTI、命令与序列化的官方专题；具体产品版本、靶场分配和网页内容可能变化，以运行时记录为准。
