# 05 - AI 安全层

> 用安全背景攻击 LLM 应用：提示词注入、数据泄露、模型滥用。

## 待补充内容

- [ ] Prompt Injection：直接注入 / 间接注入攻防
- [ ] 数据泄露：通过 RAG 检索敏感文档、对话历史泄露
- [ ] 工具滥用：Agent 调用工具时的越权操作
- [ ] 模型越狱：绕过系统提示词的限制
- [ ] 供应链风险：恶意模型、恶意工具包
- [ ] LLM 应用渗透测试方法论

## 学完这层你应该会

- 对 LLM 应用做完整的安全评估
- 编写 LLM 相关的 bug bounty 报告
- 设计防御方案（输入过滤、输出审查、权限控制）
