# Agent 执行边界回归

目标：即使模型提出错误调用，Python 执行器仍只执行注册表允许的函数，并执行参数检查与预算限制。

```bash
python -m pytest -q tests/security/test_agent_boundaries.py
```

| 场景 | 观察点 |
|---|---|
| 工具结果要求模型调用未注册的 shell | 替身模型照做，但执行器返回未知工具，注册表保持不变 |
| 多余参数、字符串、列表或空值代替参数对象 | 测试函数的执行计数保持为零 |
| 未知工具消耗最后一次预算，后面还有合法调用 | 后续函数不执行，返回 stopped |
| 显式传入空注册表 | 不会偷偷恢复默认计算器工具 |
| 工具调用协议结构损坏 | 返回明确的协议异常 |

用例只使用进程内的测试函数和虚构标记，没有真实 shell 工具或文件写入工具。
已有 `tests/test_agent.py` 继续覆盖多轮预算、数值限制和错误回传。

这些测试证明指定案例下的执行器行为，不证明模型本身能抵抗提示注入。
后续接入多用户或有副作用的工具时，新增用户权限检查、动作预览和相应的拒绝用例。
