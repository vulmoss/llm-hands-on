# 前端入口：先把交互验证完整

目前提供 Gradio 文本聊天界面：

```bash
python -m pip install -e '.[ui]'
llm-lab ui
```

浏览器访问 `http://127.0.0.1:7860`。实现位于 `src/llm_lab/ui.py`。
界面复用核心消息构建和模型流式接口，支持系统提示词及浏览器本地会话历史。
模型通过环境变量选择，避免界面展示尚未安装的固定模型列表。

## 验收

- 新会话提问，能够增量显示回答。
- 第二轮问题能够使用本会话历史。
- 新建另一个会话，消息不串用。
- 刷新后可从本地历史选择会话。
- 断开模型服务，界面出现明确错误。

## 后续扩展

优先增加 RAG 证据展示：原文、相似度、文件名和片段位置。
之后再增加工具执行记录面板和实验结果对比。
需要学习独立前端时，可调用 `llm-lab serve` 的 API；当前没有 Next.js 实现。
API 目前返回完整 JSON，如需独立前端流式体验，应先实现并测试 SSE 接口。
