# 第一周练习区

每天约两小时，按[完整学习计划](../../docs/week-01-plan.md)推进。
从仓库根目录运行脚本，不要在本目录中执行依赖相对数据路径的命令。

- [实验日志与验收表](log.md)：当天填写，完成后再勾选。
- `day01_http.py`：Day 1 从第一课复制并修改，由学习者创建。
- `day02_chat.py`：Day 2 的历史对比实验，由学习者创建。
- `notes/`：Day 4 的三篇检索资料，由学习者创建。
- `day07_assistant.py`：Day 7 独立完成的整合脚本，由学习者创建。

当前只建立计划和记录模板，没有预先完成练习或填写实验结果。
生成的 JSON 输出和索引放在根目录 `.data/week-01/`；重要结论写进日志。
